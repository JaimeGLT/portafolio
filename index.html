01 — ERP AUTOPARTES

Importadora

ERP para importadora de autopartes. Maneja inventario de productos normales y kits (piezas vendibles sueltas), importaciones masivas por Excel, caja diaria, créditos, reportes y facturación.

El corazón del sistema es el flujo de ventas con tres roles trabajando en tiempo real vía SignalR:

  • 1Cajero arma la orden, incluso parcial en un kit y la envía al almacén.
  • 2Almacenero prepara piezas y productos, marca incompleto con nota si falta algo.
  • 3Cajero/operador recibe, corrobora con el cliente y concreta la venta.

STACK

.NET 9 Clean Architecture EF Core + PostgreSQL GraphQL (HotChocolate) SignalR JWT React 18 + TS + Vite Zustand Tailwind Cloudflare R2

02 — SISTEMA PARA CAFETERÍA

Kafe Yana

Gestión integral para cafetería: inventario de productos elaborados (con recetas e insumos), comprados y combos; punto de venta con mesas y rondas de pedidos; compras, caja y fidelización de clientes con puntos y referidos.

Incluye facturación electrónica integrada con el servicio SIAT de Bolivia, notas de ajuste y contingencia incluidas, más impresión de comandas por red a cocina, barra y caja.

  • 1Recetas y costos: cálculo de márgenes de producción, módulo terminado.
  • 2POS con mesas, rondas y sub-ventas en tiempo real vía SignalR.
  • 3SIAT: facturación electrónica oficial, con manejo de contingencia.

STACK

.NET 9 EF Core + PostgreSQL GraphQL (HotChocolate) REST SignalR JWT + Cookies React 19 + TS + Vite Tailwind QuestPDF SIAT Bolivia
